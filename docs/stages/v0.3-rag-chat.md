# v0.3 — RAG Chat (embeddings only)

**Goal:** Chat that retrieves from your own documents, with partial telemetry.

**Pre-auth note:** All requests use `DEV_USER_ID` — no auth required.

## Tasks

- [ ] Drizzle schema: `chat_sessions` and `messages` tables + migration
- [ ] OpenRouter LLM call with manual tool use loop (no SDK abstraction)
- [ ] `search_embeddings` tool: embed query → cosine similarity on `document_chunks` filtered by `userId` → return top-k chunks
- [ ] SSE streaming response from `POST /chat` to frontend
- [ ] `messages.source` recorded: `parametric` (no tool called) or `embeddings` (tool called)
- [ ] `GET /chat/:id/messages` — load session history
- [ ] Chat UI: message input, streaming display, session list
- [ ] Telemetry badge per assistant message (gray = parametric, green = embeddings)
- [ ] Tests: tool call flow, source recording logic

## Deliverables

- Asking a question about an ingested document retrieves relevant chunks
- The answer streams in real time
- Each assistant message shows a telemetry badge indicating its source
- `messages` rows have correct `source` and `tool_calls` values

## Manual Testing

```bash
# Prerequisites: at least one document ingested from v0.2

# 1. Start the stack
docker compose up -d && pnpm dev

# 2. Open the chat
open http://localhost:5173/chat

# 3. Test parametric response
# Ask: "What is the capital of France?"
# Expected: gray badge (parametric) — no document needed

# 4. Test embeddings response
# Ask something specific from one of your ingested documents
# Expected: green badge (embeddings), answer references doc content

# 5. Verify in DB
psql $DATABASE_URL -c "SELECT role, source, LEFT(content, 80) FROM messages ORDER BY created_at;"

# 6. Verify streaming works
# The response should appear token by token, not all at once

# 7. Run tests
pnpm test
```

## Done When

- Parametric questions get `source = 'parametric'` badge
- Document questions get `source = 'embeddings'` badge with relevant content
- Responses stream via SSE (visible token-by-token in the UI)
- `messages` table stores correct `source` and `tool_calls` for every assistant message
- Tests pass
