# v0.5 — Authentication

**Goal:** Multi-user system with per-user data isolation enforced at every level.

## Tasks

- [ ] `apps/auth`: Better Auth setup with Drizzle adapter, JWT signing via `jose`
- [ ] Better Auth routes: sign-in, sign-up, sign-out, session, Google OAuth
- [ ] `apps/api`: JWT validation middleware applied to all routes (rejects requests without valid JWT)
- [ ] Replace `DEV_USER_ID` with `userId` extracted from validated JWT in all `apps/api` handlers
- [ ] Verify every DB query already scoped by `userId` (should be true from v0.2–v0.4)
- [ ] Login page UI (`/login`): email/password form + Google OAuth button
- [ ] Register page UI (`/register`)
- [ ] Change password page (`/change-password`)
- [ ] Protected routes on frontend: redirect to `/login` if no session
- [ ] Tests: auth flow (login → JWT → protected route), per-user embedding isolation

## Deliverables

- Register with email/password → JWT issued → access to documents and chat
- Google OAuth flow works end to end
- User A cannot see or query documents uploaded by User B
- All routes in `apps/api` return 401 without a valid JWT
- `DEV_USER_ID` env var is no longer used

## Manual Testing

```bash
# 1. Set env vars in apps/auth/.env
JWT_SECRET=...
BETTER_AUTH_SECRET=...
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...

# 2. Start the stack
docker compose up -d && pnpm dev

# 3. Register a new user
open http://localhost:5173/register
# Fill in email + password → should redirect to /documents

# 4. Test protected route (unauthenticated)
curl http://localhost:3000/documents
# Expected: 401 Unauthorized

# 5. Test protected route (authenticated)
# Get JWT from browser (check Authorization header in devtools Network tab)
curl -H "Authorization: Bearer <jwt>" http://localhost:3000/documents
# Expected: 200 with empty list

# 6. Test user isolation
# With User A: upload a document
# Log out, register User B
# User B: GET /documents → should return empty list
# User B: query chat about User A's document → should get no relevant results

# 7. Test Google OAuth
open http://localhost:5173/login
# Click "Sign in with Google" → complete OAuth flow → land on /documents

# 8. Run tests
pnpm test
```

## Done When

- Unauthenticated requests to `apps/api` return 401
- All three auth flows work: email/password login, registration, Google OAuth
- User data is strictly isolated: users see only their own documents and chats
- Tests confirm isolation at the DB query level
- `pnpm test` passes
