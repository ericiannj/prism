## Deliverables

- All three apps start without errors
- `packages/db` connects to Postgres and the pgvector extension is active
- `pnpm test` passes across the entire monorepo
- `pnpm lint` passes with no errors

## Manual Testing

```bash
# 1. Start the database
docker compose up -d

# 2. Install dependencies
pnpm install

# 3. Start all apps
pnpm dev

# 4. Check health endpoints
curl http://localhost:3000/health   # → { "status": "ok" }
curl http://localhost:3001/health   # → { "status": "ok" }

# 5. Open the frontend
open http://localhost:5173          # → blank page with no console errors

# 6. Run all tests
pnpm test
```

## Done When

- All health endpoints return 200
- Frontend renders without console errors
- `pnpm test` exits with code 0
- `pnpm lint` exits with code 0
- `docker compose up -d` + `pnpm dev` is the only setup needed
