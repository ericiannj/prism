# v0.2 — Document Ingestion

**Goal:** Upload a PDF, see chunks stored in pgvector.

**Pre-auth note:** All requests use `DEV_USER_ID` from env — no auth required yet.

## Tasks

- [ ] Drizzle schema: `documents` and `document_chunks` tables + migration
- [ ] PDF parsing with `pdf-parse`; plain text (`.txt`) and markdown (`.md`) support
- [ ] Fixed-size chunking with configurable overlap (default: 500 tokens, 50 overlap)
- [ ] Embedding generation via OpenRouter (`text-embedding-3-small`, 1536 dims)
- [ ] `POST /documents/ingest` — multipart upload, parse, chunk, embed, persist
- [ ] `GET /documents` — list documents for `DEV_USER_ID`
- [ ] Documents page UI: file upload form + document list with status indicator
- [ ] Integration tests: full ingestion pipeline (upload → chunks in DB)

## Deliverables

- Upload a PDF via the UI → document appears in the list with `status: ready`
- Chunks and embeddings are stored in `document_chunks`
- `DEV_USER_ID` is used as `userId` for all records

## Manual Testing

```bash
# 1. Set env vars in apps/api/.env
DATABASE_URL=postgresql://...
OPENROUTER_API_KEY=...
DEV_USER_ID=test-user-1

# 2. Run migrations
pnpm --filter @repo/db migrate

# 3. Start the stack
docker compose up -d && pnpm dev

# 4. Upload a document via the UI
open http://localhost:5173/documents
# Upload a small PDF or .txt file

# 5. Verify chunks in the database
psql $DATABASE_URL -c "SELECT id, name, status FROM documents;"
psql $DATABASE_URL -c "SELECT COUNT(*), document_id FROM document_chunks GROUP BY document_id;"

# 6. Verify embeddings exist (should be 1536-dim vectors)
psql $DATABASE_URL -c "SELECT chunk_index, LEFT(content, 80) FROM document_chunks ORDER BY chunk_index LIMIT 5;"

# 7. Run integration tests
pnpm test
```

## Done When

- Uploading a PDF results in `documents.status = 'ready'` and N rows in `document_chunks`
- Each chunk has a non-null `embedding` column
- `GET /documents` returns the document with correct metadata
- Integration tests pass
