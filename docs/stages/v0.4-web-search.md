# v0.4 — Web Search + Full Telemetry

**Goal:** All three sources working; telemetry fully visible in the chat UI.

**Pre-auth note:** All requests use `DEV_USER_ID` — no auth required.

## Tasks

- [x] `search_web` tool: call Tavily Search API, return title + URL + snippet per result
- [x] `source: 'web'` detection when only `search_web` is called
- [x] `source: 'mixed'` detection when both tools are called in a single turn
- [x] `toolCalls` jsonb saved in `messages` for every tool invocation
- [x] Telemetry panel: color-coded badges (blue = web, purple = mixed)
- [x] Expandable badge: click to see the exact chunks or snippets that were used
- [x] Tests: Tavily tool invocation, mixed source detection

## Deliverables

- Asking a current-events question → blue badge (web)
- Asking a question that needs both doc context and web info → purple badge (mixed)
- Expanding any badge shows the actual source material used
- `messages.tool_calls` contains the full payloads for audit

## Manual Testing

```bash
# 1. Set env var
TAVILY_API_KEY=...   # in apps/api/.env

# 2. Start the stack
docker compose up -d && pnpm dev
open http://localhost:5173/chat

# 3. Test web source
# Ask: "What happened in tech news this week?"
# Expected: blue badge (web), answer cites web results

# 4. Test mixed source
# Ask something that requires both a doc you uploaded AND external context
# Expected: purple badge (mixed)

# 5. Expand a badge
# Click on any telemetry badge → should show the sources used

# 6. Verify DB
psql $DATABASE_URL -c "SELECT source, jsonb_pretty(tool_calls) FROM messages WHERE source IN ('web','mixed') LIMIT 2;"

# 7. Run tests
pnpm test
```

- All four source values (`parametric`, `embeddings`, `web`, `mixed`) are reachable through normal usage
